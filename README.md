
# 🃏 Loja de Cartas e Hobbys

Um projeto de **loja online** voltado para **cartas colecionáveis e hobbies**, desenvolvido com **React + Vite** e **TailwindCSS**.  

> um projeto da faculdade de ADS, Feito sozinho e as pressas para as materias de Engenharia de Requisitos
> Front-end, Banco de dado(não incluido no repositorio) e Ingles

## 🚀 Tecnologias Utilizadas

- ⚛️ **React** — Biblioteca para criação da interface do usuário  
- ⚡ **Vite** — Ferramenta de build rápida e moderna para desenvolvimento front-end  
- 🎨 **TailwindCSS** — Framework CSS utilitário para estilização responsiva e moderna  

## 📦 Funcionalidades (em desenvolvimento)

- Listagem de produtos (cartas, acessórios e itens de hobby)  
- Visualização de detalhes do produto  
- Carrinho de compras  
- Sistema de busca e filtragem  
- Design responsivo  

## 📁 Estrutura do projeto

``` md
├── src/
```

## 💡 Objetivo

Criar uma loja moderna e rápida para fãs de **cartas colecionáveis** e **hobbies asiáticos**, com foco em **experiência do usuário**, **velocidade** e **design limpo**, para um trabalho da faculdade.
